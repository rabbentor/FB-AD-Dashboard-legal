Related data may be stored in the owner's web browser or in the owner's Cloudflare account if the AI assistant is enabled. To delete data or revoke the application's access, follow the instructions below. ## วิธีที่ 1 — ลบข้อมูลจากแดชบอร์ด (Dashboard Data) ข้อมูล Access Token และการตั้งค่าที่เก็บไว้ในเบราว์เซอร์สามารถลบได้โดย: 1. เปิดแดชบอร์ดบนอุปกรณ์และเบราว์เซอร์ที่ใช้เชื่อมต่อบัญชี 2. ไปที่หน้าตั้งค่า Token 3. กดปุ่ม **“ลบออกจากเครื่อง”** 4. หากต้องการล้างข้อมูลทั้งหมดที่เว็บไซต์จัดเก็บไว้ ให้ล้าง Site Data หรือ Local Storage ของเว็บไซต์ผ่านการตั้งค่าเบราว์เซอร์ การลบข้อมูลจากเบราว์เซอร์หนึ่งจะไม่ลบข้อมูลที่อาจจัดเก็บอยู่ในเบราว์เซอร์หรืออุปกรณ์อื่น To delete access tokens and settings stored in the browser: 1. Open the dashboard on the device and browser used to connect the account. 2. Go to the token settings page. 3. Click **“ลบออกจากเครื่อง”** (Remove from this device). 4. To clear all data stored by the website, clear the website's Site Data or Local Storage through the browser settings. Deleting data from one browser does not delete data that may be stored in another browser or on another device. ## วิธีที่ 2 — ลบข้อมูลผู้ช่วย AI จาก Cloudflare (If AI Assistant Is Enabled) หากเปิดใช้งานผู้ช่วย AI ข้อมูลที่เกี่ยวข้องอาจจัดเก็บอยู่ในบัญชี Cloudflare ของเจ้าของแอป โดยสามารถลบได้ดังนี้: 1. เข้าสู่ Cloudflare Dashboard ด้วยบัญชีของเจ้าของแอป 2. ไปที่ Workers & Pages และเลือก Worker ที่ใช้กับระบบผู้ช่วย AI 3. ลบ Worker ดังกล่าว หากต้องการยุติการใช้งานระบบ 4. ไปที่ KV และเลือก Namespace ที่ระบบใช้จัดเก็บการตั้งค่าหรือประวัติการทำงาน 5. ลบข้อมูลใน Namespace ดังกล่าว หรือ ลบ Namespace หากไม่ต้องการใช้งานอีกต่อไป 6. ตรวจสอบและลบ Secrets หรือ API credentials ที่เกี่ยวข้อง หากต้องการยกเลิกการเชื่อมต่อบริการภายนอก โปรดตรวจสอบให้แน่ใจว่า Worker, KV Namespace และ Secrets ที่เลือกเป็นของแอปนี้ก่อนลบ การลบข้อมูลใน Cloudflare อาจกระทบระบบอื่นที่ใช้ทรัพยากรร่วมกัน If the AI assistant is enabled, related data may be stored in the app owner's Cloudflare account: 1. Sign in to the Cloudflare Dashboard using the app owner's account. 2. Open Workers & Pages and select the Worker used by the AI assistant. 3. Delete the Worker if the system is no longer needed. 4. Open KV and locate the Namespace used to store the assistant's settings or activity history. 5. Delete the relevant data or delete the Namespace if it is no longer needed. 6. Review and delete related Secrets or API credentials if you want to disconnect external services. Make sure the selected Worker, KV Namespace, and Secrets belong to this application before deleting them. Deleting Cloudflare resources may affect other systems if resources are shared. ## วิธีที่ 3 — ถอนสิทธิ์แอปจาก Facebook/Meta (Revoke App Access) หากต้องการยกเลิกสิทธิ์ที่แอปได้รับจากบัญชี Facebook/Meta: 1. เข้าสู่ Facebook ด้วยบัญชีที่ใช้อนุญาตแอป 2. เปิด **การตั้งค่าและความเป็นส่วนตัว (Settings & privacy) > การตั้งค่า (Settings)** 3. ไปที่ **การผสานการทำงานทางธุรกิจ (Business Integrations)** หรือหน้าการตั้งค่าแอปและเว็บไซต์ที่เกี่ยวข้อง 4. ค้นหาแอปนี้ 5. เลือก **Remove / ลบออก** และยืนยันการดำเนินการ การถอนสิทธิ์จะยุติการอนุญาตให้แอปเข้าถึงข้อมูลผ่านสิทธิ์ที่ถูกถอน แต่ไม่ได้ลบข้อมูลที่เคยจัดเก็บไว้ใน Local Storage หรือ Cloudflare โดยอัตโนมัติ จึงควรดำเนินการตามวิธีที่ 1 และวิธีที่ 2 เพิ่มเติมตามฟีเจอร์ที่ใช้งาน To revoke the application's access to your Facebook/Meta account: 1. Sign in to Facebook using the account that authorized the application. 2. Open **Settings & privacy > Settings**. 3. Go to **Business Integrations** or the relevant Apps and Websites settings page. 4. Find this application. 5. Select **Remove** and confirm. Revoking permissions stops the application from accessing data through the permissions that were revoked. It does not automatically delete data previously stored in browser Local Storage or Cloudflare. You should also follow Methods 1 and 2, as applicable. ## วิธีที่ 4 — ส่งอีเมลขอความช่วยเหลือ (Request Deletion Assistance) หากไม่สามารถลบข้อมูลด้วยตนเอง หรือต้องการสอบถามเกี่ยวกับข้อมูลที่เกี่ยวข้อง สามารถส่งอีเมลถึงผู้ดูแลแอปได้: - **อีเมล:** asdem000@gmail.com - **หัวข้อ:** `Data Deletion Request - Facebook Ads Dashboard` - **รายละเอียดที่ควรระบุ:** ชื่อแอปหรือฟีเจอร์ที่ใช้งาน ช่องทางที่เกี่ยวข้อง (Dashboard หรือ AI Assistant) และขอบเขตข้อมูลที่ต้องการให้ช่วยตรวจสอบหรือลบ ไม่ควรส่งรหัสผ่าน Facebook, Access Token, API Key หรือข้อมูลลับอื่น ๆ ทางอีเมล If you cannot delete the data yourself or have questions about data associated with the application, email the app operator: - **Email:** asdem000@gmail.com - **Subject:** `Data Deletion Request - Facebook Ads Dashboard` - **Include:** the application or feature involved, the relevant storage location (Dashboard or AI Assistant), and the data you want reviewed or deleted.
